LOS TAMALEROS — GITHUB PAGES DEPLOYMENT

Upload the CONTENTS of this folder to a GitHub repository.

The repository root should show:
- index.html
- .nojekyll
- EDIT-ME.txt
- README-GITHUB-PAGES.txt

Then:
1. GitHub repository -> Settings -> Pages
2. Under Build and deployment, Source: Deploy from a branch
3. Branch: main
4. Folder: / (root)
5. Save
6. Wait a few minutes, then use the Visit site button.

Do not upload the ZIP itself. Unzip it first and upload the files inside.
